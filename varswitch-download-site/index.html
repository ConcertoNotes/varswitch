macOS

点开屏幕左上角的苹果菜单 > 关于本机，「芯片」一栏写着 Apple M 系列就选第一个，写着 Intel 就选第二个。

Apple 芯片 Intel 芯片

打开时提示「已损坏，无法打开」？
  1. 在「苹果菜单」>「关于本机」确认芯片类型，下载对应的 Apple 芯片或 Intel 版本。
  2. 打开 DMG，将 VarSwitch 拖到「应用程序」，然后退出 DMG。
  3. 打开「终端」，复制并执行下面的命令。
  4. 命令成功后，从「应用程序」打开 VarSwitch。

命令会先验证 App 签名，只在校验通过时移除 VarSwitch 自身的下载隔离标记，不会修改系统安全设置。

codesign --verify --deep --strict /Applications/VarSwitch.app && xattr -rd com.apple.quarantine /Applications/VarSwitch.app

如果签名校验报错，请删除安装包并从本站重新下载；不要跳过校验或单独移除隔离标记。经 Apple 公证的版本无需此步骤。

常见问题。

安装前只需要知道这些。

这个工具主要解决什么问题？

它帮你管理 Claude Code / API 的 Key、Base URL 和本地配置同步，避免手动改环境变量。

macOS 提示「已损坏，无法打开」怎么办？

确认从本站下载了正确芯片版本后，到下载区按步骤验证签名并放行。签名校验失败时请重新下载，不要跳过检查。

切换配置后需要重启终端吗？

系统环境变量通常需要新打开的终端才能读取最新值。已经打开的终端建议重启。
